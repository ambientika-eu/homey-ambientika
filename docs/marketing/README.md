# Graphics for the product pages

`homey_graphics.py` renders the hero (1600×700, SMART and OFFICE) and the step graphic (1600×560) in the 11 shop languages.
It needs the product images `assets/smart.jpg` and `assets/office.jpg` (cover images from the shop, not in this repository).
"Homey" appears as plain text only, no third-party logo.
